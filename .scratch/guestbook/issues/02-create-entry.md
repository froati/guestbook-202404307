# 02: 방명록 글 작성

**What to build:** 방문자가 목록 위의 작성 폼에 작성자 이름, 메시지, 글 비밀번호를 입력해 제출하면 새 방명록 글이 목록 맨 위에 바로 나타난다. 글 비밀번호는 해시로만 저장된다. 입력값 중 하나라도 비어 있거나 공백뿐이면 거부되고 어떤 칸이 비었는지 안내가 나오며, 입력한 값은 유지된다. 성공하면 폼이 비워진다.

스펙: `.scratch/guestbook/spec.md` (방명록 글 모듈 "작성", 비밀번호 해시, 서버 로직, 입력 규칙, UI, 에러 문구 항목)

**Blocked by:** 01 (방명록 글 목록 보기 + 1차 배포)

**Status:** ready-for-agent

- [ ] 작성 폼에 작성자 이름(maxLength 20), 메시지(maxLength 500, 여러 줄), 글 비밀번호(가려진 입력) 칸이 있다
- [ ] 제출은 Server Action으로 처리되고, 앞뒤 공백 제거 후 빈값이면 거부 + 안내 문구가 표시된다
- [ ] 거부되어도 입력한 값이 사라지지 않는다
- [ ] 글 비밀번호는 bcryptjs(cost 10)로 해시해 저장되고, DB에 원문이 없다
- [ ] 성공하면 새 방명록 글이 목록 맨 위에 나타나고 폼이 비워진다
- [ ] `npm run build`가 성공한다
- [ ] push 후 Vercel 배포 URL에서 작성 → 목록 반영을 직접 확인한다
