# 01: 방명록 글 목록 보기 + 1차 배포

**What to build:** 방문자가 페이지를 열면 헤더에 `방명록 · 개발자: 정윤서 (202404307)`가 보이고, 그 아래에 모든 방명록 글이 작성 시각 최신순으로 표시된다. 각 방명록 글에는 작성자 이름, 메시지(줄바꿈 유지), 한국 시간 기준 작성 시각이 나온다. 방명록 글이 없으면 비어 있다는 안내가 나온다. 이 화면이 Vercel 배포 URL에서도 동작하는 것까지 확인해 게이트 조건을 먼저 확보한다.

스펙: `.scratch/guestbook/spec.md` (Implementation Decisions의 스키마, 방명록 글 모듈 "목록 조회", 시간 표시, 렌더링 항목)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 스펙의 `CREATE TABLE entries` SQL을 Neon SQL Editor에서 실행할 수 있도록 안내하고, 테이블이 존재한다
- [ ] 방명록 글 모듈에 목록 조회가 있고, 작성 시각 내림차순으로 반환한다
- [ ] 목록 조회 결과(와 브라우저로 전달되는 데이터)에 `password_hash`가 포함되지 않는다
- [ ] 헤더에 개발자 이름 "정윤서"와 학번 "202404307"이 표시된다
- [ ] 작성 시각이 `Asia/Seoul` 기준 `ko-KR` 형식으로 표시된다
- [ ] 방명록 글이 0개일 때 빈 상태 안내가 표시된다
- [ ] 페이지가 요청마다 DB를 읽는다(빌드 시점에 정적으로 굳지 않는다)
- [ ] `npm run build`가 성공한다
- [ ] push 후 Vercel 배포 URL에서 헤더와 (빈) 목록이 에러 없이 표시된다
