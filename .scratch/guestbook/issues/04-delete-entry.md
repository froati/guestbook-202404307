# 04: 방명록 글 삭제 (글 비밀번호 확인)

**What to build:** 각 방명록 글의 [삭제] 버튼을 누르면 그 글 바로 아래에 글 비밀번호 입력란이 있는 인라인 폼이 펼쳐진다. 글 비밀번호가 맞으면 방명록 글이 DB에서 완전히 지워지고 목록에서 사라진다. 틀리면 삭제가 거부되고 그 글 옆에 "비밀번호가 일치하지 않습니다."가 표시된다. 이미 삭제된 글이면 "이미 삭제된 글입니다."가 표시된다. [취소]로 폼을 닫을 수 있다. 03의 수정 폼과 같은 방명록 글 UI 안에 공존한다.

스펙: `.scratch/guestbook/spec.md` (방명록 글 모듈 "삭제", 결과 타입 `성공 | 비밀번호 불일치 | 글 없음`, 서버 로직, UI, 에러 문구 항목)

**Blocked by:** 02 (방명록 글 작성). 같은 UI를 건드리므로 03 이후에 진행 권장

**Status:** ready-for-agent

- [ ] 방명록 글 모듈의 삭제가 `성공 | 비밀번호 불일치 | 글 없음` 중 하나를 반환한다
- [ ] 글 비밀번호 비교는 서버에서만 이뤄지고, 일치할 때만 DELETE가 실행된다
- [ ] 올바른 비밀번호 → 방명록 글이 목록에서 사라진다
- [ ] 틀린 비밀번호 → 삭제되지 않고 "비밀번호가 일치하지 않습니다."가 해당 글 옆에 표시된다
- [ ] 없는 글 → "이미 삭제된 글입니다."가 표시된다
- [ ] 비밀번호가 비어 있으면 거부 + 안내
- [ ] [취소]로 폼을 닫을 수 있고, 수정 폼과 동시에 동작해도 문제가 없다
- [ ] `npm run build`가 성공한다
- [ ] push 후 Vercel 배포 URL에서 올바른/틀린 비밀번호 두 경우를 직접 확인한다
