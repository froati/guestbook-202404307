# 03: 메시지 수정 (글 비밀번호 확인)

**What to build:** 각 방명록 글의 [수정] 버튼을 누르면 그 글 바로 아래에 인라인 폼이 펼쳐진다. 폼에는 기존 메시지가 미리 채워진 입력란과 글 비밀번호 입력란이 있다. 글 비밀번호가 맞으면 메시지만 바뀌고 작성자 이름·작성 시각·목록 순서는 그대로다. 틀리면 수정이 거부되고 그 글 옆에 "비밀번호가 일치하지 않습니다."가 표시되며, 입력한 새 메시지는 유지된다. 이미 삭제된 글이면 "이미 삭제된 글입니다."가 표시된다. [취소]로 폼을 닫을 수 있다.

스펙: `.scratch/guestbook/spec.md` (방명록 글 모듈 "메시지 수정", 결과 타입 `성공 | 비밀번호 불일치 | 글 없음`, 서버 로직, UI, 에러 문구 항목)

**Blocked by:** 02 (방명록 글 작성)

**Status:** ready-for-agent

- [ ] 방명록 글 모듈의 메시지 수정이 `성공 | 비밀번호 불일치 | 글 없음` 중 하나를 반환한다
- [ ] 글 비밀번호 비교는 서버에서만 이뤄지고, 일치할 때만 UPDATE가 실행된다
- [ ] 올바른 비밀번호 → 메시지가 바뀌고, 작성 시각과 목록 순서가 유지된다
- [ ] 틀린 비밀번호 → 메시지가 바뀌지 않고 "비밀번호가 일치하지 않습니다."가 해당 글 옆에 표시된다
- [ ] 없는 글 → "이미 삭제된 글입니다."가 표시된다
- [ ] 새 메시지나 비밀번호가 비어 있으면 거부 + 안내
- [ ] 실패해도 입력한 새 메시지가 유지되고, [취소]로 폼을 닫을 수 있다
- [ ] `npm run build`가 성공한다
- [ ] push 후 Vercel 배포 URL에서 올바른/틀린 비밀번호 두 경우를 직접 확인한다
